# 🐕 Сайт-визитка груминг салона

Современный, адаптивный сайт-визитка для мастера по грумингу собак. Разработан с акцентом на мобильную версию.

## ✨ Особенности

- 📱 **Mobile-first дизайн** - оптимизирован для мобильных устройств
- 🎨 **Красивые анимации** - плавные переходы и эффекты
- 🖼️ **Слайдер работ** - демонстрация выполненных работ
- 💳 **Карточки услуг** - детальное описание с ценами
- 📞 **Быстрая связь** - интеграция с WhatsApp, Telegram и телефоном
- ⚡ **Быстрая загрузка** - оптимизированная производительность
- 🎯 **SEO-friendly** - оптимизирован для поисковых систем

## 🛠️ Технологии

- **Vue 3** - современный фреймворк
- **Vite** - быстрая сборка
- **CSS3** - анимации и адаптивный дизайн
- **Unsplash API** - качественные placeholder изображения

## 📦 Установка и запуск

### 1. Установите зависимости

```bash
npm install
```

### 2. Запустите development сервер

```bash
npm run dev
```

Сайт откроется автоматически по адресу: http://localhost:3000

### 3. Сборка для продакшена

```bash
npm run build
```

Готовые файлы будут в папке `dist/`

### 4. Предварительный просмотр продакшен-версии

```bash
npm run preview
```

## 📝 Настройка контента

### Изменение информации о мастере

Откройте `src/components/HeroSection.vue` и измените:

- **ФИО**: строка 12 - `<span class="gradient-text">Анна Иванова</span>`
- **Опыт работы**: строка 16 - `<span class="badge-number">8+</span>`
- **Фото**: строка 9 - замените URL изображения
- **Описание**: строка 24-27

### Изменение услуг

Откройте `src/components/ServicesSection.vue` (строки 44-82):

```javascript
const services = ref([
  {
    title: 'Название услуги',
    description: 'Описание услуги',
    price: 'от 2500 ₽',
    duration: '2-3 часа',
    image: 'URL изображения',
    features: ['Тег1', 'Тег2']
  }
])
```

### Изменение контактов

Откройте `src/components/ContactsSection.vue` и измените:

- **Телефон**: строки 31 и 73 - `+79991234567`
- **WhatsApp**: строка 73 - `https://wa.me/79991234567`
- **Telegram**: строка 82 - `https://t.me/username`
- **Адрес**: строка 14
- **Режим работы**: строка 22

### Замена изображений

#### Метод 1: Использование своих фото

1. Создайте папку `src/assets/images`
2. Добавьте свои изображения
3. Импортируйте и используйте их в компонентах:

```javascript
import masterPhoto from '@/assets/images/master.jpg'
```

#### Метод 2: Использование внешних URL

Замените URL в компонентах на ссылки на ваши изображения (например, из облачного хранилища).

## 🚀 Деплой

### Vercel

```bash
npm install -g vercel
vercel
```

### Netlify

```bash
npm run build
# Загрузите папку dist на Netlify
```

### GitHub Pages

1. Установите пакет:
```bash
npm install --save-dev gh-pages
```

2. Добавьте в `package.json`:
```json
"scripts": {
  "deploy": "npm run build && gh-pages -d dist"
}
```

3. Деплой:
```bash
npm run deploy
```
