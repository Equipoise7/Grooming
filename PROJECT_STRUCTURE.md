# 📂 Структура проекта

## Основные файлы

```

│
├── 📄 index.html                    # Главная HTML страница
├── 📄 package.json                  # Зависимости проекта

│
├── 📁 src/                          # Исходный код
```

## 💡 Советы по работе со структурой

### ✅ Хорошие практики:

1. **Не меняйте имена файлов** - это сломает импорты
2. **Делайте резервные копии** перед большими изменениями
3. **Используйте Git** для версионирования
4. **Тестируйте после каждого изменения**
5. **Комментируйте свои изменения**

### ⚠️ Чего не делать:

1. Не удаляйте `node_modules/` (создается npm install)
2. Не редактируйте `package-lock.json` вручную
3. Не коммитьте `dist/` в Git (создается при сборке)
4. Не меняйте структуру компонентов без понимания
